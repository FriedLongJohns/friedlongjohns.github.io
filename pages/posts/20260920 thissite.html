This Website

Why didn't I just use Wix or Wordpress?

I feel like most personal sites these days are built with Wix, Google Sites, or some other drag-and-drop builder, or prompted out of a chatbot and dropped onto a host.

I wrote the HTML myself, mostly because of the time-honored programming myth: I thought it would be easy.

I'll admit I started with a prototype from Claude: some colors, the carousel code, and a rough layout. It was fine, but AI-generated sites tend to lack a little soul, so everything since that first draft is my own work. Fighting HTML and CSS until things sit where I want them is a pain, but I've done my best to make the site look like mine.

It's hosted on GitHub Pages as a plain folder of files: one JavaScript file, a config file, and the rest is static HTML, CSS, and assets.

If you know how websites work, I hope you appreciate this one.

PS: This website is inspired by sites like motherfuckingwebsite and suckless. I recommend checking them out!
